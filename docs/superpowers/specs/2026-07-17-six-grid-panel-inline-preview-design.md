# 六宫格裁剪分镜直接预览设计

## 目标

六宫格裁剪完成后，每张分镜卡直接显示当前有效图片。用户不需要通过“预览当前”或“预览裁切”等重复按钮才能查看图片，也不会被带到无效的媒体网址。

## 交互设计

- 分镜卡主图继续显示 `panel.imageUrl`，点击主图只打开站内图片预览弹窗。
- 六宫格裁剪分镜的小操作栏只保留“重新裁切”“放大”和可用时的“撤销”。
- 删除小操作栏中的“预览当前”“预览裁切”“预览放大”“预览源图”入口。
- 图片预览弹窗不再提供会打开新网址的“查看原图”链接；关闭按钮和点击遮罩关闭行为保持不变。
- 整张六宫格的生成、上传、裁切、放大及顶部控制区域不在本次修改范围内。

## 数据与错误处理

不改变六宫格图片生成、媒体持久化或裁切数据结构。主图仍使用现有媒体解析结果，因此本次修改不会复制图片地址或引入新的媒体请求。图片加载失败继续由现有图片组件处理，不再提供可能失效的新窗口链接作为兜底。

## 验收标准

1. 六宫格裁剪分镜卡直接显示当前图片，并可点击打开站内预览。
2. 小操作栏不再出现任何“预览……”按钮。
3. “重新裁切”“放大”“撤销”行为不受影响。
4. 站内预览弹窗不再显示“查看原图”，也不会打开新标签页。
5. 非六宫格分镜的主图点击预览仍正常工作。

## 测试范围

- 组件测试验证六宫格小操作栏只渲染处理操作。
- 组件测试验证站内预览弹窗没有外链。
- 现有分镜根级预览与六宫格控件测试继续通过。
