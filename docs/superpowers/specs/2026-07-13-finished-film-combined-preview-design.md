# 成片页全分镜连续预览设计

## 目标

在小说推文的成片生成页面增加一条由所有分镜“当前选中视频”组成的连续预览。用户可以点击任意分镜节点快速跳转；片段切换、加载失败和缺失视频均不得产生黑屏。

本功能只组合每个分镜当前选中的一个版本，不生成候选视频的排列组合。

## 页面位置与交互

连续预览位于成片页工具栏之后、配音面板和分镜卡片之前。区域包含：

1. 一个固定的 Remotion Player。页面不会为不同分镜创建或切换多个播放器。
2. 播放、暂停、上一分镜、下一分镜和当前时间/总时长控制。
3. 一条可横向滚动的分镜节点导航。

节点按现有 `allPanels` 的剧情顺序排列。六宫格分镜保留组边界，并按 `groupSequence`、`gridCellIndex` 的投影顺序显示；普通分镜沿用剧本片段顺序和 `panelIndex`。

每个节点显示分镜缩略图、镜头序号、有效时长和状态。状态包括：视频可用、使用静态分镜图、正在生成、生成失败、缺少媒体。节点本身不修改生成状态。

点击节点时：

- 选中对应节点并将统一播放器定位到该节点的起始帧；
- 播放器原本播放则继续播放，原本暂停则保持暂停；
- 横向节点条自动滚动，使活动节点保持可见；
- 快速连续点击时，以最后一次点击为准，不创建新的播放器实例。

播放器自然播放跨入下一分镜时，活动节点随当前帧自动更新。

## 当前视频来源

预览与现有成片卡片的选择保持一致：

- 面板已选择口型同步版本且 `lipSyncVideoUrl` 存在时，使用口型同步视频；
- 否则使用 `videoUrl`；
- 没有可用视频时使用 `imageUrl` 作为静态画面；
- 连分镜图也缺少时显示带状态说明的非黑色占位画面。

节点稳定身份使用 `panelId`；旧数据缺少 `panelId` 时使用 `storyboardId + panelIndex` 作为回退键。视频重新生成、口型同步偏好切换或时长修改时只更新对应节点，不重建整个预览状态。

有效时长优先级为：

1. `durationOverride`；
2. `estimatedDuration`；
3. 分镜文本中的 `duration`；
4. 默认 3 秒。

时长被转换为项目预览帧率下的整数帧，并保证至少一帧。

## 连续时间线与无黑屏保证

预览使用单一 Remotion composition。所有媒体序列在同一个帧空间中排布。

相邻片段默认使用最多 15 帧的短溶解，实际重叠长度不超过任一相邻片段时长的四分之一。时间线总时长和每个节点的起始帧都从同一投影函数计算，避免节点定位与播放器画面不一致。

在重叠区间：

- 前一片段从不透明线性降为透明；
- 后一片段从透明线性升为不透明；
- 两者透明度之和始终为 1，因此不会露出黑色底层。

片段无视频时，静态分镜图完整参与相同的时间线和溶解逻辑。视频层下面始终保留该分镜图或非黑色占位层；视频未解码、缓冲或加载失败时，底层仍可见。视频准备完成后才显示视频层。

播放器外层根据活动节点预加载前一个、当前和后一个视频。预加载窗口变化时释放不再需要的 blob URL；失败的预加载不会阻止节点跳转或整条预览。

播放结束后播放器停在最后一帧，不切换为空白画面。

## 数据边界

新增纯投影模块负责把 `VideoPanel[]` 和口型同步偏好映射为不可变预览时间线。它输出：

- 有序预览项；
- `startFrame`、`endFrame`、`transitionFrames`；
- 总时长；
- `panelKey -> item` 索引；
- 根据当前帧解析活动节点的函数。

React 组件不重新实现排序、时长或帧位置计算。播放器、节点导航和控制条均消费同一个投影结果。

现有分镜卡片生成、首尾帧链接、配音、下载和导出接口不在本功能中修改。连续预览是成片页的只读组合视图。

## 异常与边界行为

- 空分镜列表：显示“暂无可预览分镜”，不挂载 Remotion Player。
- 视频缺失：显示静态分镜图并保留节点时长。
- 图片和视频都缺失：显示非黑色状态占位，继续时间线。
- 视频生成中：节点显示生成中，播放器使用静态分镜图。
- 视频失败：节点显示失败，播放器使用静态分镜图，不中断后续片段。
- 媒体 URL 更新：维持当前 `panelKey`；若仍存在则按该分镜的相对进度重新定位。
- 当前分镜被删除：定位到删除位置之后的下一项；没有下一项则定位到最后一项。
- 快速跳转：同步更新活动键和帧，旧预加载完成不得把播放器拉回旧节点。

## 性能

- 时间线投影只在 `allPanels`、口型同步偏好或帧率变化时重算一次。
- 活动节点通过有序帧区间的二分查找解析，不在每次帧更新时遍历所有节点。
- 节点缩略图使用惰性加载；只预加载活动窗口内最多三个视频。
- Player 组件身份稳定，不因活动节点或媒体加载状态变化而重新挂载。
- 高频 `frameupdate` 只更新活动节点发生变化时所需的 React 状态。

## 可访问性与本地化

节点使用按钮语义，支持键盘聚焦、Enter/Space 跳转和明确的活动状态。播放器控制提供本地化标签。新增中文和英文文案，避免硬编码用户可见字符串。

## 测试与验收

### 纯逻辑测试

- 当前视频来源选择与口型同步偏好一致；
- 时长优先级正确；
- 普通分镜和六宫格顺序稳定；
- 片段重叠后起始帧、总时长和节点定位一致；
- 任意转场帧的前后透明度和为 1；
- 按当前帧解析活动节点使用对数级查找；
- 视频缺失和媒体全缺失仍产生可播放项。

### 组件测试

- 渲染全部节点及状态；
- 点击节点调用统一播放器的 `seekTo(startFrame)`，不重新挂载播放器；
- 播放状态在跳转前后保持；
- 当前帧跨越边界时高亮节点更新；
- 前一、当前、后一视频进入预加载窗口，离开窗口后释放；
- 缺失或失败媒体显示静态/状态占位而非黑屏；
- 快速点击最终停在最后点击的节点。

### 集成回归

- 成片页工具栏、配音面板和分镜卡片继续正常渲染；
- 口型同步版本切换后组合预览使用相同版本；
- TypeScript、ESLint、单元测试和成片阶段相关回归全部通过。

## 非目标

- 不生成同一分镜多个候选视频的排列组合；
- 不替代现有 AI 剪辑器或持久化编辑器时间线；
- 不在本次增加新的服务端拼接或渲染任务；
- 不改变成片导出格式、计费或视频生成接口；
- 不修改视频文件本身，仅提供页面连续预览。
